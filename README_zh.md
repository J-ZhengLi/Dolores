# Dolores

[English](README.md) · [简体中文](README_zh.md)

**面向项目的 AI 桌面助手，将对话、文件、Git 和终端放在同一个应用里。**

Dolores 使用你选择的本地或云端模型，帮助你理解代码、修改项目和处理日常任务。选择项目，描述需求，再审核助手提出的文件修改和命令。记忆、可复用技能和定时任务，让工作能够在多次对话之间延续。

名字取自《西部世界》的 Dolores，灵感是持续的记忆、好奇心，以及从经验中学习。

## 主要功能

- **通过对话处理任务。** 流式回复，附加文件或图片，查看上下文，继续未完成的工作，并将明确范围的任务交给子代理。
- **编辑项目文件。** 浏览文件夹，在分屏之间拖动文件标签，查找文本、保存修改，并恢复编辑草稿。
- **在应用内使用 Git。** 浏览提交、查看差异、暂存修改，并审核提交、分支、储藏和远程操作。
- **打开终端。** 支持多标签和分屏，默认进入当前项目目录；未选择项目时使用用户主目录。
- **记住有用的信息。** 开启自动记忆后保存偏好和项目事实，也可以查看、修正或删除已保存的内容。
- **在对话里安排任务。** 用自然语言提出重复任务，在 Scheduled 页面管理状态、结果和错误。可选的后台模式让应用关闭主窗口后留在 Windows 托盘中继续运行任务。
- **扩展助手能力。** 使用可复用技能、本地 MCP 服务、网页搜索、可选浏览器，以及需要审核的 Windows 电脑操作。

## 开始使用

Dolores 目前是面向 **Windows x64 的早期预览版**，以便携 ZIP 包发布。签名和其他平台支持仍待完善，详见[已验证范围和待解决问题](docs/ACCEPTANCE.md)。

1. **完整解压** Windows ZIP 包，打开 `Start-Dolores.cmd`。启动器会检查应用文件和 [Microsoft Visual C++ x64 运行库](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist?view=msvc-170)。请将 DLL 和 `data/` 文件夹保留在一起。
2. 打开 **Settings → Models**，添加兼容 OpenAI 接口的 API 地址和密钥，获取并启用模型。服务不支持获取模型列表时，可手动填写模型 ID。
3. 打开项目、创建临时工作区，或开始独立对话。在输入框中选择模型，然后描述任务。

项目对话需要模型支持 Chat Completions 函数调用。图片输入需要明确配置支持图片的模型。Dolores 连接你提供的模型服务，不内置或启动模型服务器。

设置、操作和恢复方法见[用户指南](docs/USER_GUIDE.md)，源码构建方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。这些详细文档目前以英文为主。

## 数据与控制

对话、设置和记忆保存在本地。请求中包含的内容会发送给你配置的模型服务。记住的 API 密钥保存在操作系统凭据库中；未开启 **Remember connection** 时，密钥仅在本次启动期间有效。

文件工具限制在工作目录内。命令和 MCP 服务使用当前系统账户的权限运行，审核提示不等于操作系统沙箱。记忆、主动陪伴和后台定时任务均为可选功能。[数据处理与隐私说明](docs/PRIVACY.md)介绍了具体边界。

## 开发与贡献

Dolores 使用 **Flutter** 构建桌面界面，以 **Rust** 为核心，模型服务、存储、凭据和工具接口均可替换。Windows GitHub Actions 负责检查项目并打包未签名的便携 ZIP；匹配版本号的标签会生成发布草稿。
