# Practical file and command work

`read_text_file` pages larger text automatically. Use `start_line`/`line_count` (1–120), or `start_byte`/`max_bytes` with the returned `nextByte` for long lines. JSON escaping can shorten a page without making source unreadable. Files above 1 MiB are streamed and hashed with bounded memory; no full-file read allocation is required. The digest covers the full UTF-8 file. Cancellation remains responsive during scanning. Atomic editing snapshots retain their separate 1 MiB allocation. Default discovery excludes generated/dependency folders; an explicitly selected folder named `build`, `target` or similar remains searchable. Credential/VCS and alias protections still apply.

`edit_text_file` still replaces one unique exact occurrence and reviews a bounded diff. Files above 16 KiB require `expected_snapshot` from a ranged read; any supplied snapshot must match. The prepared full snapshot is rechecked before publication. Unicode and uniform LF/CRLF behavior is retained. Changes keeps local before/after snapshots up to 1 MiB, enabling reviewed conflict-aware revert. This is not an atomic multi-file transaction.

`run_command` accepts optional `timeout_seconds` (1–300) and `capture_bytes` (1024–262144). Defaults remain 30 seconds and 8192 bytes. The reviewed request exposes actual limits; task deadlines can stop a command earlier. A literal command automatic grant covers only limits within the defaults; larger limits require a new review unless full task access is enabled. No shell fallback or command rollback is added.

Large output spills to uniquely created `dolores-command-output-*.log` files in the working folder; a formatted `dolores-command-log-*.txt` may also accompany an escaped preview. These files can be opened locally or read in ranges. Capture bounds memory, not execution lifetime. Preview shortening, process exit, complete retained output and log-write failure are separate facts. Logs may contain private output and remain user-managed local files; conversation export contains the reference/preview, not external log-file contents. No automatic log upload occurs.
