# Repeatable regression checks — brick 7.3

Run from the repository: `rtk proxy python -I -B scripts/run-regressions.py`. Windows, Python 3.11+, RTK, Rust, Flutter and the normal desktop build prerequisites are required. The default Flutter SDK is `output/toolchains/flutter`; override with `--flutter-sdk`. The existing build helper prepares dependencies and plugin junctions before analysis/tests. Close the normal app before rebuilding to release its owned bundle files; the runner never kills user apps.

The runner checks its recovery logic, Rust format/lint/workspace tests, the normal release build, Flutter analysis/widgets, then eight native fixture pairs: task feedback, context comparisons, continuation, generation profiles, coding repair, exact edits, automatic memory and skill drafts. Save and restore run in separate processes using fresh isolated directories, loopback HTTP and synthetic data. No configured live credentials/history are read. Source hashes and the bundled bridge hash identify the evidence; no live-model or native input acceptance is inferred.

Each stage has a deadline (build 900 seconds, Rust lint/tests 300, Flutter tests 180, fixture stages 120). A failed exit, invalid/missing receipt, reported live request, timeout or interruption stops the selected run. Earlier logs, data and JSON/Markdown reports remain. Timeout/interrupt terminates the runner-owned process tree; this is process cleanup, not a sandbox. A fixture must explicitly report its stage, success and nonnegative fixture/zero live request counts. Python isolated mode keeps assertions active despite inherited Python configuration. No automatic rerun occurs.

Inspect `output/regressions/run-*/report.md` and the named stage log, repair the cause, then start another fresh run. `--directory` chooses a fresh absolute directory strictly beneath `output/`; existing destinations are refused. Reports update after each stage and never label an incomplete selected scope successful. Raw fixture data/logs are private ignored outputs; do not publish them as an acceptance artifact.

Use `--case context-comparisons` (repeatable) to select fixture pairs. `--native-only` explicitly skips build/lint/unit/widget work and records an existing bundle hash with **no fresh-build claim**. Even a full passing run covers only the eight named flows. Qwen/DeepSeek behavior requires separate bounded authorized probes; selected fixture passes do not establish general model competence, low-end performance, macOS/Linux, keyboard/IME/accessibility, packaging or signing.
