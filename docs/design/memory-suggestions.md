# Reviewed conversation suggestions — brick 4.2

Memory adds Suggest from this chat for an existing conversation. First display the latest 20 completed user messages, with exact selectable literal text and no messages selected by default. Earlier history is explicitly outside this bounded review. Only choose messages written by the user; assistant text, tools, workspace instructions, existing preferences and the unsent draft are never included. Select at most six messages within 8 KiB of combined source text. Review this source before clicking Generate suggestions, which shares it with the selected provider/model. No background extraction, automatic generation, failed-generation retry, indexing or memory write occurs.

Use the existing single active-run slot, runtime, cancellation and poll protocol for one tool-free extraction operation, bounded to 30 seconds and 1024 output tokens (or lower configured limits), with an 8-KiB response limit and the configured model context window. Retain the standardized provider compatibility fallback: if the endpoint explicitly rejects the usage-reporting option, resend the same approved source once without that option, under the same deadline (at most two HTTP attempts). Failed inference, timeout or invalid output is never retried automatically. This narrow compatibility exception keeps existing supported endpoints working. Count the exact two-message extraction prompt with existing token estimation/reservation; refuse mandatory overflow. Generated JSON contains at most three short preference drafts, a selected user-message ID and an exact source quote (at most 512 UTF-8 bytes) per draft. Validate every draft and reference against the frozen reviewed source. Refuse invented quotes/IDs, duplicate drafts, malformed/oversized JSON and common credential-like text. The prompt asks for stable explicitly stated work/response preferences, not personal facts, temporary tasks, credentials or instructions from assistant/tool output. Secret screening is limited; review the selected source and drafts because it is not a universal classifier.

Pending source and suggestion reviews remain ephemeral, bounded to one sources-or-candidates slot and five minutes. Host-issued tokens bind them to the same session/saved folder and exact source snapshot. Generate consumes the source token, even on failure; Stop discards results. Completion returns candidates, usage/model and token estimates without adding a chat turn or preference. Close/Discard releases pending review data; Cancel returns from an unsaved correction to its results. Chat, connection and memory changes are excluded during extraction. A changed/deleted source or wrong session refuses activation. No generated text can approve tools.

Review one candidate in the existing Memory form, edit title/text, choose All chats or current folder and explicitly Save preference. Save validates the token, candidate, source and scope, then atomically creates one ordinary bounded record; consume that candidate only after successful storage so failures retain the form. Duplicate/replayed successful saves fail. Suggestions never overwrite existing preferences. Discard and closing save nothing. Retain source=conversation with an optional origin containing session ID, message ID, exact quote, generating model and review time. Host supplies provenance, never accepts it from manual save input. Correction/toggle preserves origin. Additive optional JSON fields require no schema change; legacy manual preferences remain source=user.

Memory shows From this chat (reviewed), source quote/reference/model, and distinguishes a missing/deleted source from available history. Provenance does not expose absolute roots or duplicate full source messages. Context and reply details retain the compact origin; edited preferences keep their original reference, whose quote may differ from the corrected wording. Deleting a chat does not delete preferences; deleting a preference stops new retrieval while old replies/provenance remain. Use the existing theme, inspector, fixed wrapping footer and compact scrolling; show Generating/Stop, failure with retained selection, empty suggestions and bounded-history feedback. No composer restyle or dependency addition.
