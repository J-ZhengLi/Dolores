# Everyday controls after milestone 15

Use the bottom-left Settings entry. Search finds all settings destinations; optional
technical controls are expandable. These are implemented paths, not prototype links.

| Earlier entry | Current entry |
| --- | --- |
| Appearance | Settings → General |
| Model connection / Request settings | Settings → Models → choose model → Responses |
| Response defaults / scope tuning | Settings → Advanced → Response defaults / Scope overrides |
| Dolores settings | Settings → Personalization (All chats by default) |
| Memory / project knowledge | Settings → Memory → My preferences / Project facts |
| Remember a message | Hover/focus your message → Remember this → edit and Save |
| Web search / Browser / Computer use | Settings → Tools; readiness overview first |
| Ordinary computer use | Ask in a working chat → Share window (also in composer plus menu) |
| Permissions | Composer Access, or Settings → Tools → Chat access |
| External tools | Settings → Tools → Connections → Add / Import JSON → review launch |
| Skills | Settings → Tools → Skills → Import / Create / Draft from chat |
| Tool trials / skill learning | Settings → Advanced → Skill testing & learning → Skill testing / Learning experiments |
| Harness mods | Settings → Advanced → Harness extensions |
| Task limits | Settings → Advanced → Task limits; paused replies link directly |
| Summary / context preview | Composer context ring → Context; Usage details / Summary details expand |
| Trajectory / local request log | Activity → Conversation / Requests |
| Run history / checkpoints | Activity → Earlier tasks → select task → evidence / Prepare resume draft |
| Changes / restore | Changes → select file → diff → Review revert → explicit confirmation |
| Workspace instructions | Chat details → Project instructions |
| Fork conversation | Chat actions → Branch chat |
| Markdown / JSON / attachment exports | Chat actions → Export → select format |
| Unused-attachment cleanup | Settings → Advanced → Diagnostics & storage → Attachment storage |
| Compare instructions / capabilities / source | Settings → Advanced → Diagnostics & storage → named destination |
| Feedback / usage / attachment previews | Existing reply and attachment controls |

Side chats retain no file tools. Global preference/skill management is available
before first send. Project facts offers Start working session for an unsaved working
chat; explicit project/temporary selection remains necessary for side chats.
Activation, sharing and consequential action reviews remain separate decisions.
