# Reviewed project skills — brick 5.1

This foundation loads standard [Agent Skills](https://agentskills.io/specification) files from a saved working folder's `.agents/skills/<name>/SKILL.md`. It deliberately starts with user selection; generation from successful work and measured promotion belong to later bricks. Side chats have no project skills. No global discovery, implicit activation, watcher or model request runs in the Skills inspector.

Review reads one nonlinked UTF-8 regular file, at most 8 KiB, validates YAML `name`/`description`, and shows its complete literal text. Names match their direct directory and the specification's ASCII naming rules. Other metadata is accepted as data; `allowed-tools` cannot approve tools. References/scripts/assets remain literal and require the existing separately approved tools. Review never executes files.

Activate stores a reviewed snapshot for this folder, shared by its project/temporary chats. Source changes require a new review to take effect; they do not silently replace the active snapshot or prevent use of the reviewed version. Disable preserves versions. Roll back reviews a retained version and publishes a new version containing that exact text, without modifying project files. Forget removes all local versions and future retrieval; it leaves source files and historical reply provenance intact.

One host review token binds session/root/record revision/exact text and expires after five minutes. Activation consumes the token, rechecks the file (or saved rollback version), then performs an atomic compare-and-swap. Failures preserve old state and require another review. Only one review slot exists. Inspector close cancels it. All operations use the existing active-run exclusion.

Bounds: inspect at most 128 directory entries, return up to 32 sorted eligible names with an explicit partial notice; store at most 12 records/folder including disabled, retain five latest versions/record; enable at most three skills with at most 8192 combined source bytes. Activations beyond these limits refuse, rather than silently omit skills. State revision advances on each mutation; version advances on activation/rollback. Timestamps are Unix milliseconds. SQLite schema 14 adds one folder/name-keyed JSON table; no background workers or new runtime processes.

Preview and send use the same saved snapshots. Exact reviewed skill text is counted as mandatory system input alongside AGENTS.md, memory, summary, function schemas and framing. A model window too small for mandatory input fails before transport. Context, started events, saved replies and exports retain skill name/source/version/review-time/rollback provenance; only the local next-message preview additionally returns full snapshots. Host tool policy and direct user requests outrank skills. No permission, capability or request limit can be granted by skill text.

Reuse the system palette and InspectorFrame. A quiet Skills header action opens a compact, scrolling folder list with Enabled/Disabled/Available labels. Review shows exact literal source, description, active version, retained versions and clear snapshot behavior. Refresh/Back and Activate/Disable/Forget controls stay in a wrapping fixed footer. Rollback requires reviewing old text then Activate version. Close never activates; pending local writes lock dismissal/duplicate actions and chat switching. The composer remains unchanged.

Acceptance covers frozen parsing/path/scope/approval/persistence/context cases, synthetic native provider wire/restart/export and light/dark compact rendering. This foundation does not claim task improvement, generated-skill quality, automatic selection or cross-platform OS input acceptance.
