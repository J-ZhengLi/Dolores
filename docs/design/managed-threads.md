# Thread forks and managed context

Chat actions → Fork conversation copies history through a selected completed assistant turn, up to 100 turns and 1 MiB. The new chat shares the original working folder, including temporary folders. It does not copy drafts, active runs, permission grants, thread settings or summaries. Historical receipts remain evidence; paused continuation authority is removed. The copy is transactional and survives deletion of its parent. Files are shared, not isolated.

Session summary offers an opt-in, chat-specific automatic compaction switch. Before a send that would omit older turns, the host makes at most one tool-free summary request, capped at 1024 output tokens and 30 seconds. It locally narrows the source to a contiguous complete batch that fits the configured model window. The call consumes a model-call allowance; remaining task time is reduced. The host preserves the original goal literally, summary coverage, model/revision and recent run provenance. Full history and receipts stay local. Summaries remain fallible context and grant no authority.

Malformed, credential-like, truncated, oversized or failed results preserve the previous valid summary and draft. A valid summary may still be insufficient for a tiny window: the send stops with manual-summary/window recovery instead of looping. Read-only context preview makes no model request. Mid-tool context overflow retains existing checkpoint/ranged-read recovery rather than automatically summarizing or retrying tools.

Instruction review includes the root and nested AGENTS.md files inside the chosen folder. Each nested snapshot is labeled with its relative path; it applies only beneath that path, with deeper guidance taking precedence there. Parent directories outside the chosen folder and includes are not read. Discovery excludes hidden/build/output dependency directories, walks at most four levels and 64 directories, includes at most eight nested files, and refuses aggregate guidance above 8 KiB. Changes require a fresh review. These bounds are disclosed coverage, not an exhaustive repository index.

Activated skills retain project-over-global precedence. The prepared context contains a bounded name/description catalogue and exact instructions only for skills matching the current draft by name or description keywords of at least four characters. Mention a skill name to force selection. Context inspection shows selected snapshots; this is explicit keyword matching, not semantic retrieval. Activation, review and permission rules remain binding.
